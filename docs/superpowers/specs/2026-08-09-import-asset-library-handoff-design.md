# 导入页与素材库衔接设计

## 目标

在导入步骤的视频与 Gaussian 场景卡片中增加对应素材库入口，并修复从共享素材库选择
项目输入后 `ingest` 未运行、导致“下一步”持续不可用的问题。

## 交互

- “选择源视频”旁显示“从素材库选择”，进入视频素材页签。
- “选择 Gaussian 场景”旁显示“从素材库选择”，进入 PLY 素材页签。
- 从导入页进入素材库时，路由携带当前项目 ID 作为受限返回上下文。成功选择素材后自动
  返回该项目的导入步骤。
- 从顶部全局导航进入素材库时不携带返回上下文，选择素材后留在素材库。
- 选择请求进行时禁用同页的素材选择操作，避免重复提交。

返回上下文只接受当前活动项目的导入步骤。缺失、格式错误或项目 ID 不匹配时按全局
素材库处理，不执行任意路由跳转。

## 状态流

素材库仍以 `selectProjectAsset` 返回的 `ProjectDto` 作为权威状态。选择成功后，应用先接收
该项目快照；若快照中的视频和 PLY 摘要都存在，且 `ingest` 尚未成功，则通过现有
`runStage('ingest')` 入口启动输入处理。这样文件导入和素材库选择共享同一任务准入、
任务事件与项目刷新机制，不增加组件本地的伪完成状态。

只有一种素材时不启动 `ingest`。两种素材齐全但已有任务占用时，现有任务准入规则继续
拒绝重复任务并显示错误。素材选择本身已经成功时不回滚项目引用；从导入页进入的用户
仍返回导入页查看权威状态和错误。

## 组件边界

- `ImportPage` 只渲染两个类型明确的素材库链接，不自行推断或启动素材库选择流程。
- `AssetLibraryPage` 负责选择请求的单次提交，并把返回的权威项目快照交给应用层。
- `App` 负责验证返回上下文、接收项目快照、启动 `ingest`，以及按来源决定是否返回导入
  步骤。
- `project-store` 的步骤可达性规则保持不变：“下一步”仍只在 `ingest` 权威成功后可用。

## 错误处理

- 选择素材失败：停留在素材库，保留原项目状态并显示现有错误提示。
- 启动 `ingest` 失败：保留已选择的素材，显示任务准入错误；上下文入口返回导入页。
- 返回上下文无效：忽略返回请求并停留在素材库。

## 验证

前端回归测试覆盖：

1. 两张导入卡片分别链接到视频和 PLY 素材页签，并携带当前项目返回上下文；
2. 上下文入口选择素材后返回当前项目导入步骤；
3. 只有一种素材时不启动 `ingest`；
4. 两种素材齐全且 `ingest` 未成功时只启动一次 `ingest`；
5. 顶部导航进入素材库时选择后不自动跳转；
6. `ingest` 成功后“下一步”恢复可用；
7. 无效或不匹配的返回上下文不会跳转。

完成自动化测试后，使用真实 Edge 验证视频入口、PLY 入口、选择返回和“下一步”解锁的
完整流程。
