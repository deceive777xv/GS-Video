# 项目卡片操作区微调设计

## 目标

消除项目卡片中重复的流程状态，并把低频管理操作收敛为紧凑符号，让“继续制作”保持为唯一的底部主操作。

## 卡片布局

- 卡片左上角继续显示“当前项目”或“本地项目”。
- 删除右上角原有的流程步骤文本，在同一位置放置删除符号 `×`。
- 项目名称与重命名符号 `✎` 放在同一行，符号紧邻名称右侧。
- 卡片详情区继续显示“最近更新”和“流程进度”，这里是唯一的流程状态展示位置。
- 卡片底部只保留“继续制作”按钮。

## 交互与可访问性

- `×` 复用现有删除确认框，不直接删除项目；任务运行时继续禁用。
- `✎` 复用现有重命名弹窗与失败保留行为。
- 两个符号按钮都提供明确的 `aria-label` 和 `title`，键盘焦点样式沿用现有全局规则。
- 不改变项目创建、打开、重命名、删除的数据流与后端接口。

## 样式

- 符号按钮使用透明背景和紧凑点击区域；删除符号使用现有危险色，编辑符号使用弱化文字色。
- 项目名称保持单行截断，编辑符号不随长名称一起被挤出卡片。
- 不调整首页整体配色、卡片尺寸或栅格布局。

## 验证

- 更新首页组件测试，确认卡片右上角删除按钮、名称旁重命名按钮及底部唯一主操作。
- 验证符号按钮仍能打开原有弹窗，忙碌状态仍会禁用删除和继续制作。
- 运行完整前端测试、TypeScript 检查与生产构建。
