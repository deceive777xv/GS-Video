# GS Video 合成后处理设计

状态：已确认

## 目标

在固定的“抠像修边 → Alpha 合成 → 导出编码”主流程中加入可选、可组合、可重复、可排序的合成后处理效果链。代表帧、完整低分辨率视频预览、全分辨率处理后缓存与最终导出必须使用同一数学效果引擎和同一项目配置。

首版同时把抠像修边和导出编码升级为项目级可配置能力，并保持桌面端与浏览器连接模式的功能对等。

## 非目标

- HDR、HLG、PQ、BT.2020 或其他广色域工作流
- 关键帧、时间轴或逐帧效果覆盖
- 曲线、三向色轮、HSL 分区或局部蒙版调色
- 模糊、颗粒、降噪、色差、镜头畸变、文字或水印效果
- Mask 时序稳定、补洞、人物重建或 AI 细节生成
- 1D LUT、Hald CLUT、图片 LUT 或厂商专有 LUT
- MOV/ProRes、WebM/AV1、GIF、图片序列或硬件视频编码
- 跨项目效果链预设与多人协同编辑
- 生产环境 CPU 后处理回退

## 权威工作流

后端阶段图调整为：

`ingest → segment → solve_camera → map_trajectory → render → composite → post_process → export`

- `composite`：读取源前景、权威 Mask 和 GS 渲染帧，执行项目级抠像修边与线性光 Alpha 合成，发布全分辨率 16-bit 无损基础合成帧。
- `post_process`：按项目中的有序效果链处理基础合成帧，发布全分辨率 16-bit 无损处理后帧和完整时长的低分辨率预览 MP4。
- `export`：只读取权威处理后帧，根据项目导出编码配置生成并验证最终 MP4。

空效果链仍执行 `post_process` 阶段并发布经过验证的无效果结果，使 `export` 始终只有一个权威输入契约。

## 失效边界

| 修改 | 首个失效阶段 | 后续失效 |
| --- | --- | --- |
| 抠像修边 | `composite` | `post_process`, `export` |
| 效果链内容、顺序、启用状态、Mix 或参数 | `post_process` | `export` |
| LUT 内容身份 | `post_process` | `export` |
| 效果实例显示名称 | 无 | 无 |
| 代表帧查看位置 | 无 | 无 |
| 导出编码配置 | `export` | 无 |

缓存键使用效果实例的有效顺序、类型、参数、启用状态、Mix、LUT 内容哈希、色彩上下文和实现版本。显示名称、草稿撤销历史和代表帧位置不进入像素缓存键。

## 色彩与位深契约

- 首版对外色彩契约固定为 SDR Rec.709。
- 明确标记为 BT.2020、PQ、HLG 或其他不受支持色彩的源视频拒绝导入。
- 色彩元数据缺失或 unspecified 时，用户必须明确确认按 SDR Rec.709 解释；该假设写入项目输入契约并进入缓存键。
- 源前景与 GS 背景按 SDR Rec.709 编码值解释，并在线性光中执行 Alpha 合成。
- 效果引擎接收 `float32` 图像与显式色彩上下文。
- 效果链保留超出 `0…1` 的浮点中间值；只有效果自己的有限输入域和最终输出转换可以映射或钳制。
- 基础合成帧与处理后帧使用带清单的 16-bit 无损 RGB 缓存；清单至少记录位深、通道、传递函数、色彩原色、尺寸、帧数和实现版本。
- 最终 H.264/H.265 MP4 固定输出带 Rec.709 原色、传递函数和矩阵元数据的 limited-range 8-bit `yuv420p`。
- 16-bit RGB 到 8-bit YUV 的转换使用确定性抖动，不能直接截断。
- HDR 扩展未来通过新的色彩上下文、输入/输出转换、缓存格式能力和效果能力声明加入，不复制业务阶段图。

## 抠像修边

抠像修边属于固定的 `composite` 阶段，不是效果实例。首版只做逐帧空间处理：

- 整体启用：默认开启
- 边界偏移：`-20…+20` 全分辨率源像素，默认 `-1px`；负值收缩，正值扩张
- 羽化半径：`0…20` 全分辨率源像素；默认映射到当前 1px 修边的等效柔化
- 颜色净化强度：`0%…100%`，默认 `0%`
- 颜色净化采样半径：`1…20` 全分辨率源像素，默认 `3px`

代表帧和低分辨率预览按比例换算空间参数。关闭整体修边时直接使用权威原始 Mask。颜色净化只处理 Alpha 边缘附近的前景颜色，不修改 Mask 权威；不执行跨帧稳定、补洞或人物重建。

旧项目和新项目均采用兼容默认修边设置，“重置”回到该默认，而不是关闭修边。

## 效果链模型

效果链是项目级、有序、全片静态的效果实例列表，最多 32 个实例；禁用实例也计入上限。同一种效果可以重复出现。

每个效果实例包含：

- 稳定且不复用的实例 ID
- 效果类型与参数版本
- 可选用户显示名称
- 启用状态
- 通用 Mix：`0%…100%`，默认 `100%`
- 效果类型对应的严格参数对象

通用 Mix 按 `input * (1 - mix) + effect(input) * mix` 定义。禁用实例完全旁路。添加的基础校色使用中性参数；3D LUT 选择素材后才创建；Bloom、暗角和锐化使用轻微但可见的推荐默认值。

首版不支持关键帧。项目 schema 统一承担效果参数演进；旧应用遇到更高项目 schema 时沿用现有策略拒绝加载并提示升级，不部分加载未知效果。

## 首版效果目录

### 基础校色

作用于整帧，不包含曲线、色轮、HSL 分区或局部 Mask。

- 曝光：`-5…+5 EV`，默认 `0`
- 对比度：`-100…+100`，默认 `0`
- 高光：`-100…+100`，默认 `0`
- 阴影：`-100…+100`，默认 `0`
- 色温偏移：`-100…+100`，默认 `0`
- 色调偏移：`-100…+100`，默认 `0`
- 饱和度：`0%…200%`，默认 `100%`
- 自然饱和度：`-100…+100`，默认 `0`

后端为产品级数值提供版本化、确定性的数学映射；项目不保存 UI 之外的隐藏调色参数。

### 3D LUT

- 只支持标准 3D `.cube`。
- 支持 `LUT_3D_SIZE` 与 `DOMAIN_MIN` / `DOMAIN_MAX`，导入时严格验证有限数值、完整样本数与安全尺寸上限。
- 在 SDR Rec.709 归一化 RGB 上使用四面体插值。
- LUT 输入按文件域映射，域外值按该效果的明确契约处理。
- LUT 不另设强度参数，只使用通用 Mix。

### Bloom

从整帧高亮区域提取亮度、柔化扩散并叠加回画面；不读取人物 Mask 或物体轮廓。

- 亮度阈值：`0%…200%` SDR 参考白，默认 `80%`
- 柔和过渡：`0%…100%`，默认 `50%`
- 扩散半径：`1…256` 全分辨率输出像素，默认 `32px`
- 强度：`0%…400%`，默认 `25%`
- 辉光颜色：RGB，默认白色

### 暗角

基于输出画布归一化坐标的可偏心椭圆压暗，不读取人物 Mask。

- 强度：`0%…100%`，默认 `20%`
- 中点/范围：`0%…100%`，默认 `50%`
- 羽化：`0%…100%`，默认 `50%`
- 圆度：`-100…+100`，默认 `0`
- 中心 X/Y：`-100%…+100%`，默认 `0`

### 锐化

仅对亮度应用反遮罩锐化，不执行 AI 超分辨率、去模糊或细节生成。

- 强度：`0%…300%`，默认 `50%`
- 半径：`0.1…10` 全分辨率输出像素，默认 `1px`
- 阈值：`0%…10%` SDR 亮度差，默认 `1%`

Bloom 和锐化半径在代表帧与低分辨率预览中按输出缩放比例换算。暗角始终使用归一化坐标。

## LUT 素材

- `.cube` 导入后复制到 GS Video 管理的共享素材库，按内容哈希去重。
- 项目效果实例只引用 LUT 素材 ID；缓存键使用 LUT 内容身份，不使用名称或原始路径。
- 桌面路径导入和浏览器上传最终都进入同一托管导入流程。
- 外部源文件移动或删除不影响项目。
- LUT 被任一项目引用时禁止删除，并列出引用项目；删除项目不自动删除共享 LUT。

## GPU 执行

- 代表帧与全片使用同一数学效果引擎和隔离 CUDA worker 协议。
- 不允许生产环境静默回退 CPU；CUDA 不可用、worker 初始化失败或运行环境不完整时返回可修复错误。
- 后期处理页按需维持预热预览会话；新请求取消或丢弃旧请求，只显示最新帧与最新草稿。
- 离开页面、切换项目、启动全片任务或关闭应用时终止预览会话并释放显存。
- 全片任务使用独立批处理生命周期，通过现有 GPU 门禁管理。
- 按显存预算选择帧批量与分块尺寸；无法整帧处理时保持原分辨率并使用带足够重叠的分块。
- 分块只允许影响速度，不得改变像素结果或产生接缝；最小安全分块仍失败时返回可修复的显存不足错误。
- 每帧完成后发布进度并检查取消；未完成树不得成为权威 artifact。

## 代表帧与视频预览

- 参数、开关、顺序或查看帧变化后，前端防抖请求真实后端代表帧。
- 用户可以用帧滑杆或时间码选择任意源帧；默认人物提示帧，最后查看位置作为界面偏好保存，但不进入项目像素语义或缓存键。
- 代表帧支持基础合成与当前草稿的可拖动分割对比，以及不修改配置的临时整链旁路。
- 用户显式点击后才生成 `post_process` 视频预览。
- 视频预览覆盖源视频完整时长、完整帧率与音轨，只降低空间分辨率；移除当前 150 帧上限，不抽帧或截短。
- 低分辨率预览固定使用快速 H.264 内部编码，不套用最终导出的编码器、码率模式或压缩档位。
- 代表帧、视频预览和最终处理帧共享同一修边、Alpha 合成和效果实现。

## 草稿、保存与冲突

- 添加、删除、复制、排序、启停、重命名和调参先进入页面草稿。
- 代表帧使用草稿，不立即修改项目权威状态。
- “保存效果链”一次性提交；“生成处理后预览”先原子保存草稿，再启动任务。
- 离开页面存在未保存修改时提示保存或放弃。
- 草稿支持会话内撤销/重做和 `Ctrl+Z` / `Ctrl+Shift+Z`；连续滑块拖动合并为一个历史步骤，保存后清空历史。
- 单个效果可重置、复制；整链可清空。首版不提供跨项目预设库。
- 效果链拥有单调 revision；保存提交 expected revision，陈旧 revision 返回冲突并保留本地草稿，不自动合并或静默覆盖。

## 前端工作流

工作流扩展为六步：

1. 导入素材
2. 选择人物
3. 调整机位
4. 预览合成：轨迹、裁剪、抠像修边与基础合成
5. 后期处理：效果链、代表帧对比与处理后视频预览
6. 导出成片：编码配置与已验证文件保存

后期处理页采用大预览与右侧效果链工作台：主区包含代表帧、前后分割对比、帧滑杆和视频播放器；右栏包含可排序、可折叠的效果卡片和参数；顶部提供添加、撤销、重做、保存；底部提供生成处理后预览。窄窗口下右栏移到主区下方。排序必须同时提供拖动和键盘/按钮操作。

桌面端与浏览器连接模式共享全部后处理 API 与 UI。唯一平台差异仍是最终成片保存：桌面端选择本地目标，浏览器下载已验证 artifact。

## 导出编码

首版固定 MP4 封装与 AAC 音频，支持：

- 视频编码：H.264（默认）或 H.265/HEVC
- 码率模式：恒定质量（默认）或双遍 VBR 目标码率
- 质量等级：`1…100`，默认 `70`，分别映射到两个编码器的版本化参数
- 目标码率：`0.5…200 Mbps`；根据分辨率、帧率和编码器给出可覆盖的推荐值
- 压缩档位：快速、均衡（默认）、高压缩
- 音频：AAC `192 kbps`，保持源视频有无音轨的语义
- 编码后端：仅 `libx264` / `libx265`，不提供 NVENC、Quick Sync 或 AMF

修改编码配置只使 `export` 失效，不重算处理后帧或预览。导出继续执行帧数、帧率、时长、尺寸、音轨和文件身份验证，再原子发布结果。

## 项目迁移与缓存

- 项目 schema 从当前版本升级，并增加 `post_process` 阶段、抠像修边、效果链、效果链 revision、色彩假设和导出编码配置。
- 旧项目迁移后保留导入、分割、ViPE、轨迹和 GS 渲染权威。
- 旧 `composite` 标记 stale，新 `post_process` 设为 pending，旧 `export` 标记 stale，并清除旧验证导出状态。
- 旧缓存文件不在迁移时删除。
- 新基础合成与处理后缓存继续采用不可变内容寻址发布。
- 未引用的旧链缓存不自动删除；用户可先查看安全清理计划和可回收空间，再确认删除。
- 启动 `composite`、`post_process` 或 `export` 前执行带余量的磁盘容量准入检查。

## 错误与完整性

- 所有 API 与项目模型严格验证有限数值、范围、枚举、实例数和 LUT 引用。
- LUT 在进入素材库前完成解析与结构验证；运行时再次验证内容身份。
- 任何输入 artifact、项目 authority、LUT 身份或草稿 revision 在请求期间变化时，结果不得发布。
- CUDA、显存、磁盘、LUT、色彩、预览编码和最终编码错误使用可定位的错误码与恢复动作。
- 取消与失败只清理受控 staging，不修改最近一次成功权威结果。

## 验收与测试

- 项目迁移测试覆盖旧 schema、默认修边、失效边界和旧导出撤权。
- 模型测试覆盖五种效果、重复实例、32 项上限、严格参数范围、名称与 Mix。
- 数值测试覆盖 Rec.709 往返、线性 Alpha、扩展范围、基础校色、四面体 LUT、Bloom、暗角和亮度锐化。
- GPU 测试覆盖代表帧与批处理一致、整帧与分块一致、边界无接缝、显存预算、取消与 worker 清理。
- LUT 测试覆盖合法 `.cube`、域映射、非法大小、NaN/Inf、样本数、托管复制、内容去重与引用删除保护。
- 工作流测试覆盖 `composite → post_process → export`、空链、缓存复用、完整时长预览和三类失效边界。
- 导出测试覆盖 H.264/H.265、两种码率模式、三个压缩档位、Rec.709 元数据、limited-range `yuv420p`、确定性降位深和有/无音轨。
- 前端测试覆盖六步导航、草稿保存、revision 冲突、撤销/重做、拖动与键盘排序、实例重命名、LUT 选择、帧选择、前后对比、完整预览和平台保存差异。
- 端到端视觉夹具验证代表帧、视频预览与最终导出在允许的编码容差内一致。
