# GS Video MVP 产品需求文档

- 文档状态：已确认，待实施规划
- 日期：2026-07-11
- 产品暂定名：GS Video
- 目标版本：MVP

## 1. 文档目的

本文定义 GS Video MVP 的产品目标、用户流程、功能边界、系统约束、验收标准与后续演进方向。MVP 的任务不是一次性覆盖完整的 Gaussian 视频制作流程，而是验证一条足够简单、可重复的自动背景替换闭环。

## 2. 背景与问题

现有 Gaussian Splatting 视频合成通常需要先求解源视频相机，再把 Gaussian 场景、相机和素材导入 Blender 等专业工具，手动处理坐标、尺度、镜头与合成。这条链路步骤多、排错困难，也要求用户理解多个专业软件。

GS Video 将源视频和目标场景拆分为两个职责：

- 源视频提供需要保留的人物、声音和相机运动；
- 已重建的静态 Gaussian 场景提供新的环境；
- 系统通过初始机位锚定和相对相机运动迁移完成背景渲染与 Alpha 合成。

MVP 不重建源场景，也不要求把源场景与目标场景的完整点云对齐。

## 3. 产品定位

GS Video MVP 是一款面向内部测试者和技术型创作者的 Windows 桌面验证工具。桌面应用使用 Web 技术构建界面，并保持同一套前端能够在普通浏览器中连接本地服务运行。用户导入一段受控的单人短视频和一个已重建完成的静态 Gaussian 场景，通过三次关键交互生成背景替换视频：

1. 在人物上点击一次；
2. 在目标场景中确认初始机位；
3. 在目标场景中指定人物落脚点。

核心价值主张：

> 用户不需要重建源场景，不需要在 Blender 中手动匹配相机，只需选择人物、目标初始机位和落脚位置，即可获得沿原镜头运动渲染的合成视频。

## 4. MVP 目标与非目标

### 4.1 目标

- 验证三次关键交互后的自动成片流程是否成立；
- 验证相机相对运动能否稳定迁移到无关的 Gaussian 场景；
- 在 8 GB NVIDIA 显存的基准环境中完成受控的 1080p 短视频处理；
- 建立可观察、可缓存、可取消、可分阶段重试的本地处理管线；
- 建立不依赖桌面专有 API 的共享 Web 前端，使后续浏览器 UI 无需重写业务页面；
- 通过少量稳定接口隔离高变动的算法和渲染实现，为后续局部扩展保留空间。

### 4.2 非目标

MVP 不包含：

- 人物与 Gaussian 场景物体之间的深度遮挡；
- 人物深度卡片、地面接触、接触阴影、重光照或代理网格；
- 多人、多对象、多镜头自动拆分或动态 Gaussian；
- 大范围重新运镜和自由视点视频；
- 从视频或图片训练 Gaussian 场景；
- 云端处理、账户、同步或协作；
- 在线资源市场、第三方资源搜索与面向最终用户的点云下载；
- Blender、Nuke、After Effects 或 EXR 多通道集成；
- 节点编辑器、专业时间线或插件市场；
- 电影级最终画质或实时处理。

## 5. 用户与使用场景

### 5.1 目标用户

- 负责验证 Gaussian 视频工作流的内部测试者；
- 熟悉基础视频概念、但不希望手动完成三维相机匹配的技术型创作者；
- 能在 Windows 11 与 NVIDIA GPU 环境中安装和运行本地工具的用户。

### 5.2 主要使用场景

用户有一段 10 至 30 秒的单人、单镜头视频，以及一个已经重建好的静态 Gaussian 场景。他希望保留视频中的人物和音轨，将环境替换为 Gaussian 场景，并继承原视频的镜头运动。

## 6. 输入、输出与运行约束

### 6.1 源视频

- 时长：10 至 30 秒；
- 分辨率：最高 1920 × 1080；
- 内容：单个主要人物；
- 结构：单镜头，无剪辑切换；
- 镜头：固定机位、纯旋转或轻中度手持运动；
- 音频：如存在则保留原始音轨；
- 不适合大幅快速移动、人物长时间完全遮挡或离开画面的素材。

### 6.2 目标场景

MVP 输入的是已经重建完成的静态 Gaussian 点云资产，不是普通视频或图片。

- 首个支持格式：带完整 Gaussian 属性的 `.ply`；
- 属性应包括位置、尺度、旋转、不透明度和颜色或球谐系数；
- 场景不随时间变化；
- 用户可以在实时或交互式视口中浏览场景并选择机位。

从多视角视频或照片创建 Gaussian 场景属于后续独立模块，其产物通过相同场景资产接口进入本工作流。

### 6.3 运行环境

- Windows 11；
- NVIDIA GPU；
- 以 8 GB 显存作为 MVP 基准；
- 本地离线运行；
- 桌面壳使用 Tauri 2，要求系统具备可用的 Microsoft Edge WebView2 Runtime；
- 允许安装 GPU 运行时、模型文件与媒体处理依赖；
- 实时性不是验收重点，稳定完成和进度可见性优先。

“本地离线运行”约束针对 MVP 的视频处理过程。开发和验收环境允许通过独立脚本联网获取公开测试素材，但运行中的 MVP 不得自行下载、上传或遥测用户素材。后续在线资源模块只能在用户明确操作后下载公开资源，不能改变用户项目素材默认不出本机的原则。

### 6.4 输出

- 带原始音轨的 MP4 合成视频；
- 统一格式的相机轨迹 `camera.json`；
- 逐帧人物 Alpha；
- Gaussian 背景渲染帧；
- 项目参数、阶段状态、模型版本和日志；
- 可选的低分辨率预览视频。

## 7. 核心用户流程

### 7.1 创建项目与环境检查

用户选择项目目录。系统检查 GPU、可用显存、模型文件、媒体处理组件和渲染后端。环境不满足条件时阻止开始，并给出具体、可执行的修复信息。

### 7.2 导入素材

用户导入源视频和 Gaussian `.ply` 场景。系统检查视频时长、分辨率、帧率、编码、音轨，以及场景字段和显存预估。系统不得修改原始素材。

### 7.3 选择前景人物

系统显示代表帧，用户在人物上点击一次。系统生成全片人物 Alpha 并提供叠加预览。若结果不合格，用户可更换代表帧并重新点击；MVP 不提供逐帧画笔修复。

### 7.4 分析相机运动

系统估计镜头内参、相对位姿和镜头类型，并生成可信度。固定机位与纯旋转镜头使用简化运动模型；轻中度手持使用 6DoF 轨迹。可信度低于可用阈值时，系统拒绝自动生成并解释原因。

### 7.5 放置目标镜头

用户在 Gaussian 视口中浏览目标场景，确认初始相机位置、朝向和焦距。系统默认按源视频视场角初始化目标相机。

### 7.6 指定人物落脚点

用户在目标场景中点击人物脚下应对应的位置。MVP 使用该点建立构图与运动映射锚点，并自动给出运动尺度。用户可使用一个全局“运动幅度”滑杆修正平移量。

落脚点在 MVP 中不建立真实人物几何，也不用于深度遮挡或物理接触计算。

### 7.7 生成预览

系统优先生成降分辨率短预览。用户检查人物构图、背景运动方向和运动幅度，可调整初始机位、焦距和运动幅度后重新生成。修改这些参数不得触发人物重新分割或源相机重新求解。

### 7.8 最终导出

系统按源分辨率和帧率逐帧或分块渲染背景，使用人物 Alpha 合成画面，恢复音轨并编码 MP4。导出结束后显示文件路径、耗时和诊断摘要。

## 8. 功能需求

### 8.1 必须具备

- 创建、打开和保存单项目；
- 导入并校验源视频和 Gaussian `.ply`；
- 选择单个人物并生成时序 Alpha；
- 预览 Alpha 叠加效果并重新选择人物；
- 分类镜头并输出相机内参与逐帧位姿；
- 在 Gaussian 场景中交互浏览和确认初始机位；
- 设置落脚点、焦距和全局运动幅度；
- 将源相机相对运动映射到目标场景坐标；
- 生成低分辨率预览；
- 渲染、合成、恢复音轨并导出 MP4；
- 展示阶段、当前帧、已耗时和预计剩余时间；
- 支持取消和从最近成功阶段重试；
- 保存中间产物、缓存元数据和诊断日志。

### 8.2 可以延后

- 遮罩边缘的少量全局参数；
- 场景降采样副本的可视化管理；
- 多个导出预设；
- 轨迹曲线的只读诊断视图。

## 9. 系统结构

MVP 采用“共享 Web 前端 + Tauri 桌面壳 + FastAPI 本地服务 + 模块化 GPU worker”。前端业务只能通过版本化 HTTP/WebSocket API 使用后端能力，不得通过 Tauri command 承载项目或处理业务。

```text
Tauri 2 桌面壳
├─ 启动/关闭 Python API sidecar
├─ 原生文件对话框与文件管理器定位
└─ 注入本次启动的 API 地址与令牌
                 ↓
React + TypeScript + Vite SPA
├─ 桌面模式：Tauri PlatformBridge
└─ 浏览器模式：Browser PlatformBridge
                 ↓ REST + WebSocket
FastAPI（127.0.0.1 随机端口）
├─ 项目与素材 API
├─ 任务控制与事件流
├─ 项目状态、缓存和日志
└─ GPU worker 生命周期
                 ↓
视频预处理 → 人物分割 → 相机求解
                         ↓
GS 场景加载 → 轨迹映射 → 背景渲染
                         ↓
                   Alpha 合成 → 导出
```

普通浏览器模式直接加载同一套 SPA，并连接用户已启动的本地 FastAPI 服务。开发模式使用 Vite proxy；生产桌面模式由 Tauri 启动 sidecar 并等待健康检查通过后显示主界面。

### 9.1 主要模块

- **共享 Web 前端**：实现向导、视频/遮罩预览、Gaussian 视口、任务进度和导出页面；
- **BackendClient**：封装版本化 REST 与 WebSocket 协议，禁止页面直接调用 `fetch` 或拼接 API URL；
- **PlatformBridge**：隔离文件选择、导出保存、打开外部链接和在文件管理器中显示等平台差异；
- **Tauri 桌面壳**：只管理窗口、Python API sidecar、桌面能力和最小权限配置；
- **FastAPI 本地服务**：提供项目、素材、参数、任务、日志摘要与导出 API；
- **任务事件流**：通过 WebSocket 推送阶段、当前帧、总帧数、耗时、ETA、完成和错误事件；断线后可用 REST 状态接口恢复；
- **项目管理**：维护素材引用、参数、阶段状态、缓存版本和导出记录；
- **视频服务**：探测媒体信息、解码帧、提取及恢复音轨、生成代理视频；
- **人物分割适配器**：接收视频、代表帧与提示点，输出逐帧 Alpha 和置信信息；
- **相机求解适配器**：输出统一坐标约定下的内参、逐帧位姿、镜头类型和可信度；
- **场景资产服务**：校验并载入场景，提供资产元数据、交互视口和显存预估；
- **轨迹映射器**：处理初始机位、坐标系、尺度、焦距和运动平滑；
- **场景渲染器**：按场景与相机序列输出渲染通道；MVP 只要求 RGB；
- **合成器**：MVP 负责 Alpha 合成和基础边缘处理；后续可增加深度、阴影与颜色处理；
- **任务调度器**：管理阶段依赖、进度、取消、缓存、重试和错误；
- **导出器**：编码视频、恢复音轨并校验输出时长。

MVP 的默认人物分割后端为 EdgeTAM；SAM 2.1 Hiera Tiny 只作为质量和显存对照后端，不做静默自动回退。两者必须实现同一 `ForegroundSegmenter` 契约，并运行在独立、可配置的 GPU worker 进程中；桌面壳和 FastAPI 进程不得常驻分割模型。Windows 原生 Python 与 WSL Python 都可作为 worker 命令，具体可用性由环境诊断报告。

### 9.2 前后端与平台边界

- API 统一使用 `/api/v1` 前缀；请求与响应模型由后端生成 OpenAPI，前端生成或校验对应 TypeScript 类型；
- REST 负责查询和命令提交，WebSocket 只承载事件，不作为项目状态的唯一来源；
- 前端页面、状态管理和组件不得直接导入 Tauri 包；只有 `TauriPlatformBridge` 可以调用 Tauri 插件；
- 桌面文件导入由 Tauri 对话框返回本地路径，再交给后端按路径校验；
- 浏览器文件导入通过浏览器文件选择器和分块上传进入本地后端，不假定浏览器能读取绝对路径；
- Tauri 退出时先请求 FastAPI 优雅停止任务，再终止 API sidecar；Python API 负责终止仍存活的 GPU worker；
- FastAPI 意外退出时，Tauri 显示可诊断错误和日志路径，不静默反复重启正在处理的项目。

### 9.3 本地通信安全

- FastAPI 只监听 `127.0.0.1`，使用系统分配的随机空闲端口，不监听局域网地址；
- 每次桌面启动生成新的高熵会话令牌，所有 REST 和 WebSocket 连接都必须验证；
- CORS 只允许当前 Tauri 应用来源和明确的本地开发来源，不允许通配符；
- Tauri capability 只开放所需 sidecar、dialog、opener 和 reveal 权限，不向前端开放任意 shell、文件系统或任意域名 HTTP；
- Web 前端启用严格 CSP，不加载未审查的远程脚本；
- API 日志不得记录令牌、完整用户路径或素材内容。

### 9.4 项目目录

```text
project/
├─ project.json
├─ source/
├─ proxies/
├─ masks/
├─ camera/
├─ renders/
├─ previews/
├─ exports/
└─ logs/
```

`project.json` 是版本化的项目状态源，记录输入引用、处理参数、模型版本、阶段状态、缓存键和输出索引。大体积逐帧数据保存在独立目录中，不嵌入 JSON。

## 10. 可扩展性原则

MVP 保持产品范围小，只在高变动、已知需要替换的边界建立稳定契约，不提前建设面向未知需求的通用框架。

### 10.1 需要预留的接口

- `BackendClient`：允许同一 SPA 连接桌面 sidecar 或用户启动的本地服务；
- `PlatformBridge`：允许桌面文件路径导入与浏览器分块上传使用不同实现；
- `ForegroundSegmenter`：允许替换人物分割模型；
- `CameraSolver`：允许替换或组合相机求解算法；
- `SceneAsset` 与 `SceneLoader`：允许增加其他 Gaussian 格式和场景重建产物；
- `SceneRenderer`：允许从 RGB 扩展到 Depth、Alpha、Normal 等通道；
- `TrajectoryMapper`：独立处理坐标、尺度与运动映射；
- `Compositor`：允许从 Alpha 合成扩展到深度遮挡、阴影和颜色协调；
- `TaskStage`：统一阶段状态、进度、取消、缓存和错误契约；
- 版本化项目结构：允许通过显式迁移升级旧项目。

在线资源能力后续通过 `ResourceCatalogClient` 和 FastAPI 下载任务扩展。资源目录、下载、断点续传、哈希校验和许可证记录属于共享后端能力；Tauri 只提供保存目录选择、打开来源页面和在文件管理器中显示，不让资源业务绑定桌面壳。

### 10.2 不提前抽象的能力

- 4DGS 时间模型；
- 云端任务与多租户协议；
- 节点式编辑器；
- 多用户协作；
- 插件市场；
- 面向任意渲染器的通用图形接口。

MVP 验证后允许依据真实失败案例调整内部接口，但调整项目结构时必须提供显式版本迁移，不把整体推倒重写作为默认路线。

## 11. 缓存与阶段失效

- 每个处理阶段根据输入资产标识、参数、实现版本和上游产物生成缓存键；
- 相同输入和参数不得重复执行昂贵计算；
- 修改人物选择会使分割及其下游阶段失效；
- 修改目标机位、焦距或运动幅度只使轨迹映射、背景渲染、合成和导出失效；
- 修改导出编码参数只使最终导出失效；
- 任一阶段失败或取消时保留已经完整完成的前序产物；
- 不完整产物不得被标记为有效缓存。

## 12. 8 GB 显存策略

- EdgeTAM 作为默认人物分割 worker，SAM 2.1 Hiera Tiny 只在显式对照验收中启动；单次任务不得连续静默加载两个模型；
- 分割、相机求解和 Gaussian 渲染按阶段串行运行；
- 阶段结束后主动释放模型、张量和 GPU 缓存；
- 预览使用降分辨率代理和可配置抽帧；
- 最终背景允许逐帧或分块渲染；
- 允许把部分模型或数据卸载到系统内存；
- 导入场景时估算显存，必要时建议使用降采样场景副本或降低渲染分辨率；
- 显存明显不足的任务应在开始前拦截；
- 不以实时速度为目标，但长任务必须持续报告进度，界面不得无响应。

## 13. 错误处理

错误分为三类：

- **可修复问题**：给出明确操作，例如降低预览分辨率、更换代表帧或重新选择人物；
- **素材不适用**：说明被违反的输入限制，例如检测到切镜、轨迹可信度过低或人物长时间不可见；
- **系统故障**：向用户显示简洁摘要，同时保存阶段、错误类型、输入标识、参数、版本和完整日志。

桌面与 API 边界还必须处理：

- API sidecar 启动失败、健康检查超时或端口握手失败；
- WebSocket 断开后自动重连，并通过 REST 获取权威任务状态；
- API sidecar 异常退出时保留已落盘阶段状态，重新启动后允许用户手动恢复；
- Tauri 关闭期间若任务未能在超时内取消，记录强制终止原因并保留前序完整产物。

以下情况可在进入昂贵处理前主动拒绝：

- 检测到镜头切换；
- 主要人物长时间完全遮挡或离开画面；
- 大幅快速运动使相机轨迹不可信；
- Gaussian 文件缺少必要字段或无法载入；
- 预计显存明显不足；
- 视频编码损坏或不受支持。

## 14. 验收标准

MVP 使用至少 12 组固定受控案例验收，覆盖固定机位、纯旋转、小幅平移、手持行走、室内外场景、不同人物构图和不同规模的 Gaussian 场景。

| 维度 | 验收标准 |
|---|---|
| 自动闭环 | 至少 80% 的受控案例无需修改中间文件即可完成导出 |
| 关键交互 | 正常案例只要求选择人物、确认初始机位、指定落脚点 |
| 相机运动 | 输出背景运动方向正确，无明显跳帧、翻转或轨迹突变 |
| 人物分割 | 主体全片持续可见，无持续性大块缺失或背景泄漏 |
| 音视频 | 输出时长与源视频误差不超过一帧，音轨保持同步 |
| 显存 | 8 GB NVIDIA 显存基准机可完成受控的 1080p、30 秒案例 |
| 可恢复性 | 任一处理阶段失败后可从最近成功阶段重试 |
| 缓存 | 修改目标机位不重新运行人物分割和源相机求解 |
| 数据安全 | 不修改源文件，不产生任何网络上传 |
| 诊断 | 每次失败都记录阶段、错误类型、参数、版本和日志 |
| UI 可复用 | 同一 React/Vite 构建可在 Tauri WebView 和普通浏览器中完成 mock 后端向导流程 |
| 本地 API 安全 | 服务只监听回环地址；无令牌请求被拒绝；CORS 不接受未列入允许列表的来源 |

被正确识别并解释为“素材不适用”的案例不计为系统崩溃，但不计入自动闭环成功案例。

## 15. 测试策略

- **模块测试**：覆盖媒体探测、坐标变换、缓存键、项目状态、参数校验和迁移；
- **契约测试**：覆盖分割、相机、场景和渲染适配器的输入输出结构；
- **API 契约测试**：覆盖 OpenAPI 模型、鉴权、项目命令、任务状态和 WebSocket 事件；
- **前端测试**：覆盖共享页面、BackendClient、PlatformBridge 和状态恢复；
- **管线测试**：使用小型固定素材验证阶段重试、取消、缓存命中与失效；
- **端到端测试**：从创建项目运行到 MP4 导出，校验文件、帧数、时长和音轨；
- **双宿主 UI 测试**：同一 SPA 分别在普通浏览器和 Tauri WebView 中完成 mock 工作流；
- **sidecar 生命周期测试**：覆盖启动、健康检查、正常退出、异常退出和孤儿 GPU worker 清理；
- **人工视觉评估**：检查构图、背景运动、人物连续性和明显边缘缺陷；
- **显存测试**：在 8 GB 基准环境记录每阶段峰值显存，并验证串行释放和预检查。

固定受控案例所需的真实视频和 Gaussian 场景通过开发工具从官方来源联网获取，不提交大型二进制到 Git。仓库必须提交素材清单和锁文件，记录来源 URL、用途、许可证或使用条款、引用要求、文件大小与 SHA-256；下载后只有通过哈希校验的文件才能进入测试。网络不可用时允许复用已经验证的本地缓存，但缺少必需素材时验收必须失败，不能静默跳过。

首批来源采用 DAVIS 2017 官方 480p TrainVal 视频/标注，以及 Graphdeco-Inria 官方 3D Gaussian Splatting 预训练模型。后者仅用于内部研究与评估；若项目进入商业发布准备，必须替换为自有或明确允许商业使用的 Gaussian 场景。

## 16. 主要风险与控制

- **相机轨迹失败**：先识别镜头类型，为固定和纯旋转镜头使用简化模型；低可信度时拒绝生成；
- **无关场景没有唯一尺度**：使用初始机位、落脚点和运动幅度，把不可自动决定的部分收敛为创作选择；
- **人物呈现二维贴片感**：将其作为 MVP 已知限制，通过受控镜头降低影响，在 V1 引入深度合成；
- **分割边缘不稳定**：提供遮罩预览和更换代表帧，不在 MVP 引入逐帧修复器；
- **显存不足**：串行加载、代理分辨率、逐帧渲染、CPU 卸载和场景降采样；
- **算法快速变化**：通过少量适配器契约隔离实现，项目记录实现与模型版本；
- **桌面壳锁定前端**：业务通信统一走 HTTP/WebSocket，Tauri 调用只存在于 PlatformBridge；
- **本地 API 被其他页面调用**：回环绑定、逐次启动令牌、严格 CORS 和 CSP 共同限制；
- **sidecar 或 WebSocket 中断**：项目状态持续落盘，REST 作为权威状态，事件流允许重连；
- **过度设计**：不为 4DGS、云端、节点图或插件系统提前建设框架；
- **后续重构破坏项目**：版本化项目结构，结构变更必须提供迁移路径。

## 17. 版本路线

### 17.1 MVP：自动背景替换闭环

完成受控单人视频、已有 Gaussian 点云、相机运动迁移、Alpha 合成和 MP4 导出，验证交互、稳定性、8 GB 显存运行和分阶段恢复。

### 17.2 V1：深度感知合成

增加人物视频深度、Gaussian 深度、人物尺度标定、前后遮挡、地面接触和简易接触阴影。

### 17.3 V2：画质与输入泛化

增加多人或多对象、多镜头拆分、边缘精修、颜色匹配、运动模糊、景深、镜头畸变和更多 Gaussian 资产格式。

### 17.4 V3：Gaussian 场景重建

新增独立“创建场景”入口，接受多视角视频或照片，完成抽帧与质量检查、相机求解、Gaussian 训练、场景检查与裁剪，并输出可被现有场景资产接口载入的资产。

场景重建与背景替换保持项目级解耦，使重建失败不会混淆背景替换管线的验证结果。

### 17.5 在线资源与浏览器入口

在 MVP 验证后，可增加在线 Gaussian 资源目录、缩略图或轻量点云预览、用户触发下载、本地资源库和许可证记录。完整下载由 FastAPI 任务执行并通过 WebSocket 报告进度；必须支持 HTTPS、域名策略、断点续传、取消、大小限制、磁盘预检查、SHA-256 或签名校验以及 PLY/SPZ 实际格式验证。

同一阶段可提供普通浏览器入口。浏览器 UI 连接本地服务，项目页面与桌面版共享；浏览器无法直接提供绝对路径时，使用分块上传或后端托管资源库。

### 17.6 专业扩展

根据前述版本的实际使用结果，再评估同场景重定位、动态 Gaussian、自由视点视频、EXR 多通道与专业软件集成。

## 18. MVP 发布判定

同时满足以下条件时，MVP 验证完成：

1. 受控测试集自动闭环成功率达到 80%；
2. 8 GB 显存基准机能完成规定的 1080p、30 秒案例；
3. 三次关键交互可以驱动正常案例完成导出；
4. 阶段取消、失败重试和缓存失效通过管线测试；
5. 输出视频的帧数、时长与音轨同步符合验收标准；
6. 已知失败类型均有可理解的拒绝或错误信息；
7. 同一 SPA 已在 Tauri 和普通浏览器模式通过 mock 向导测试；
8. 本地 API 的回环绑定、会话令牌、CORS 与 sidecar 生命周期测试通过；
9. 项目格式、主要模块契约和后续迁移原则已有测试覆盖。
