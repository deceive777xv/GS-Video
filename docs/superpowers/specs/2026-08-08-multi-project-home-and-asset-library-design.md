# 多项目首页与共享素材库设计

日期：2026-08-08

## 1. 背景

GS Video 当前在进程启动时从运行配置读取一个固定 `project_root`，并围绕该目录装配
项目仓库、文件锁、任务执行器、预览会话和 GPU worker。React 前端没有页面级路由，
启动后直接恢复当前项目的五步工作流；左上角 Logo 只跳到工作流内容锚点。浏览器或
Tauri WebView 中点击鼠标右键还会显示浏览器原生的前进、后退和刷新菜单。

本次改动把应用提升为单窗口、多项目管理模式：启动进入项目首页，用户可以创建、
继续、重命名和删除多个项目；所有项目共享一个独立素材库，视频与 PLY 分开管理。
导入源文件不再复制进各项目目录。Logo 在所有页面返回项目首页，同时全局关闭浏览器
原生右键菜单。

## 2. 目标

- 增加项目首页，支持新建、继续、重命名和删除项目。
- 项目卡片显示最近更新时间与当前工作流进度。
- 同一后端进程管理多个项目，同一时刻只允许一个活动项目。
- 增加共享素材库，视频和 PLY 使用两个独立页签。
- 素材导入后复制到共享素材库，以 SHA-256 去重；项目只保存素材 ID。
- 被项目引用的素材禁止删除，并向用户列出引用项目。
- 删除项目时删除项目配置、缓存与生成结果，但不删除共享素材。
- Logo 始终返回项目首页；顶部提供“项目”和“素材库”全局入口。
- 禁用浏览器和 Tauri WebView 的原生右键菜单，不增加自定义右键菜单。
- 安全、可重复地迁移现有单项目数据。

## 3. 非目标

- 不支持把项目建在用户任意选择的外部目录。
- 不支持多个项目同时运行任务或同时持有活动 GPU 会话。
- 不增加项目复制、归档、搜索或排序设置。
- 不增加素材视频播放、PLY 三维预览、文件夹或标签分类。
- 不自动删除未引用素材，也不在删除项目时级联删除素材。
- 不增加自定义右键菜单。
- 不改变五步工作流的业务顺序、质量参数或 GPU 调度规则。

## 4. 方案选择

采用“单一后端进程 + 项目目录管理器 + 单活动项目会话”。应用级服务长期存在，
负责项目目录、共享素材库、环境检测与修复以及显存设置；项目级服务由活动项目会话
持有，负责项目仓库、项目锁、工作流任务、预览和项目产物路径。

不采用切换项目时重启 Python 后端的方案，因为它会增加 Tauri 生命周期复杂度、延长
切换时间，并使浏览器开发模式与桌面模式产生差异。不采用每项目独立工作进程，因为
当前产品不需要并行编辑或并行任务，其资源调度和进程治理成本超出本次范围。

## 5. 存储布局与领域模型

### 5.1 应用数据布局

运行配置提供应用数据根目录。开发环境默认位于 `.runtime/data`，生产环境由桌面宿主
提供应用本地数据目录。数据根目录下分离存放项目、素材和应用级索引：

```text
data/
  catalog.json
  projects/
    .trash/
    <project-id>/
      project.json
      proxies/
      masks/
      cameras/
      renders/
      composites/
      exports/
      logs/
  assets/
    index.json
    videos/
      <sha-prefix>/<sha256>.<extension>
    ply/
      <sha-prefix>/<sha256>.ply
    .staging/
```

项目目录不保存导入的视频或 PLY。项目缓存、预览、导出和其他可再生成或项目专属的
产物仍保存在对应项目目录中。共享素材库是项目库之外的应用级区域。

### 5.2 项目目录

`catalog.json` 是项目发现和活动项目记录的权威索引，至少包含目录 schema 版本、
项目 ID 列表和最近活动项目 ID。项目名称、创建时间、更新时间及工作流状态仍以每个
项目的 `project.json` 为权威，项目列表摘要从这些文件读取并校验，避免目录索引成为
第二份可漂移的完整项目状态。

`Project` schema 增加 `updated_at`，并把 `source_video` 与 `scene_ply` 路径字段替换为
`source_video_asset_id` 与 `scene_ply_asset_id`。项目每次权威保存时更新 `updated_at`。
项目名称去除首尾空白、限制为 1 至 80 个 Unicode 字符，并在整个项目库中禁止不区分
大小写的重名。项目 ID 继续使用 UUID，目录名只来自经过验证的项目 ID。

### 5.3 素材模型

素材索引中的每一项至少包含：

- `asset_id`：稳定 UUID；
- `kind`：`video` 或 `ply`；
- `original_filename`：用户导入时的显示名称；
- `size` 与 `sha256`：内容身份；
- `stored_relative_path`：相对于对应素材根目录的路径；
- `imported_at`：首次成功导入时间；
- 视频或 PLY 的既有探测摘要。

内容身份使用 `(kind, sha256, size)`。相同种类和内容的重复导入返回已有素材，不生成
第二份文件，也不覆盖首次导入的显示名称。视频与 PLY 即使字节相同也不会跨种类复用。

项目读取输入时必须通过 `AssetLibrary.resolve(asset_id, expected_kind)` 获取只读绝对
路径。解析器重新验证索引、文件大小、普通文件属性、目录边界以及 Windows 重解析点，
不允许工作流直接拼接或信任素材索引中的路径。

## 6. 运行时与项目切换

### 6.1 应用级服务

应用级服务包含：

- `ProjectCatalog`：项目创建、枚举、重命名、删除和目录锁；
- `AssetLibrary`：素材导入、去重、解析、引用查询和删除；
- 环境检测与修复服务；
- 显存预算服务；
- 认证、应用级事件和共享配置。

`ProjectCatalog` 对目录级修改串行化，并用临时文件加原子替换保存索引。目录扫描和
索引读取均严格校验，不把任意目录名或损坏 JSON 暴露为项目。

### 6.2 活动项目会话

`ActiveProjectManager` 持有零个或一个 `ActiveProjectSession`。会话包含项目仓库与锁、
项目路径、任务执行器、预览服务以及与当前项目绑定的工作流服务。应用可以停留在首页
或素材库而不进入工作流；此时上次项目仍可保持活动状态，但不会自动跳转到工作流。

项目切换只允许在当前项目没有排队或运行任务时执行。切换采用两阶段处理：

1. 在目录锁内校验目标项目存在且不等于当前项目；
2. 读取并迁移目标项目 schema，获取目标项目实例锁；
3. 构造目标仓库、路径和惰性项目服务，确认目标会话可用；
4. 再次确认当前项目没有排队或运行任务；
5. 暂停并排空当前实时预览，清除旧任务事件权威；
6. 原子替换活动会话和活动项目记录；
7. 关闭旧会话并释放旧项目锁与项目相关资源；
8. 恢复目标项目的实时预览能力。

目标校验、锁定或构造失败时保持当前项目不变。切换提交后目标预览恢复失败时保留已经
切换的项目，但关闭预览会话并返回可重试资源错误；下一次预览请求可以重新初始化。
任务运行时，切换和删除项目都返回稳定冲突错误，绝不自动取消后台任务。

删除项目时，先验证任务状态与精确目录身份，再把项目目录原子重命名到
`projects/.trash/<project-id>-<deletion-id>`。随后提交项目目录索引，并在删除当前项目
时关闭活动会话、清除活动项目记录。索引提交失败时把暂存目录原子移回；提交成功后
递归清理暂存目录。清理失败只保留内部待清理记录，不让已删除项目重新出现在首页。
删除非活动项目不影响当前会话，删除操作不可级联到共享素材库。

## 7. 素材导入、选择与删除

### 7.1 导入事务

浏览器分块上传与 Tauri 本地路径导入最终使用同一素材提交事务：

1. 在 `assets/.staging` 中独占创建临时文件；
2. 流式复制或接收数据，同时计算 SHA-256、大小和进度；
3. 使用既有媒体或 PLY 探测器验证格式并生成摘要；
4. 在素材索引锁内按 `(kind, sha256, size)` 查重；
5. 命中时删除本次临时文件并返回已有素材；
6. 未命中时把临时文件原子移动到内容寻址路径；
7. 原子保存素材索引后返回新素材。

取消、探测失败、空间不足或索引保存失败只清理本次持有的临时文件，不改变已有素材、
项目引用或工作流状态。索引提交前若内容文件已移动但保存失败，恢复逻辑删除仅由本次
事务新建且仍未被索引引用的文件。

### 7.2 项目选择素材

导入步骤可以从共享素材库选择已有视频和 PLY，也可以导入新素材后立即选择。选择或
更换素材通过项目修改事务保存素材 ID，并继续调用现有失效规则：更换视频使人物、
机位、预览和导出等下游状态失效；更换 PLY 使目标机位、预览和导出等相关下游状态
失效。素材本身保持不可变，因此多个项目可以安全引用同一文件。

素材库页面的“用于当前项目”只在存在活动项目且没有冲突任务时可用。没有活动项目时
保留浏览和导入能力，但提示用户先打开或新建项目。

### 7.3 引用保护删除

删除素材前，后端在项目目录锁和素材索引锁保护下重新读取所有有效项目的素材 ID。
只要存在引用，就返回冲突响应和引用项目的 ID、名称列表，不删除索引或内容文件。
没有引用时，先从索引原子移除素材，再删除对应内容文件。若内容文件删除失败，保存
一条可恢复的待清理记录并向用户报告，不把仍可被项目解析的半删除素材留在索引中。

## 8. API 设计

所有接口继续受现有一次性会话令牌保护。

### 8.1 Bootstrap

Bootstrap 响应增加项目摘要列表、活动项目和素材库摘要。`project` 改为可空：全新安装
或删除最后一个项目后没有活动项目。前端所有测试替身必须显式提供这些新增字段及空闲
默认状态，不允许依赖缺失字段推断。

### 8.2 项目接口

- `GET /api/v1/projects`：返回项目摘要列表；
- `POST /api/v1/projects`：创建、激活并返回新项目；
- `PATCH /api/v1/projects/{project_id}`：重命名并返回项目摘要；
- `DELETE /api/v1/projects/{project_id}`：删除项目；
- `POST /api/v1/projects/{project_id}/activate`：切换并返回活动项目；
- `GET /api/v1/projects/current`：保持现有语义，返回活动项目；
- 现有 `/api/v1/projects/current/...`：继续操作活动项目。

没有活动项目时，`/projects/current` 及其子接口返回稳定的
`active_project_required` 项目错误。项目重名、目标被占用、任务冲突和项目损坏分别
使用稳定错误码，不在消息中暴露本地绝对路径。

由于新建项目会立即激活它，新建也属于项目切换操作。当前项目存在排队或运行任务时，
后端在创建任何目录前拒绝请求，避免留下未激活的孤立项目；前端同时禁用“新建项目”。

### 8.3 素材接口

- `GET /api/v1/assets?kind=video|ply`：按单一种类返回素材与引用摘要；
- `POST /api/v1/assets/import-local`：Tauri 本地路径导入；
- `POST /api/v1/assets/uploads` 及分块子接口：浏览器可恢复上传；
- `DELETE /api/v1/assets/{asset_id}`：删除未引用素材；
- `PATCH /api/v1/projects/current/assets`：选择或清除当前项目的视频/PLY 素材。

本地路径导入仅接受 Tauri 认证会话允许的 loopback 请求，并沿用现有普通文件、重解析
点、大小和类型校验。浏览器上传永远不能提交服务端本地路径。

## 9. 前端信息架构与交互

### 9.1 路由与共享外壳

前端使用轻量 hash 路由，不新增路由依赖：

- `#/`：项目首页；
- `#/assets/video`：视频素材；
- `#/assets/ply`：PLY 素材；
- `#/projects/<project-id>/workflow/<step>`：指定项目的工作流步骤。

直接打开工作流 URL 时，前端先激活 URL 中的项目，再按现有可达性规则恢复请求步骤；
不可达步骤回退到该项目当前可达步骤。浏览器前进、后退和刷新通过 hash 路由恢复，不与
右键菜单禁用耦合。

`AppHeader` 是所有已认证页面共享的顶栏。Logo 使用可聚焦链接指向 `#/`；“项目”和
“素材库”是两个全局入口。活动项目名称、环境状态与显存设置按当前上下文展示。现有
五步工作流由 `WorkflowApp` 承载，任务恢复和权威状态规则保持不变。

### 9.2 项目首页

首页默认按 `updated_at` 降序显示项目卡片。每张卡片包含项目名、最近更新时间、当前
工作流步骤和“继续项目”按钮。卡片溢出菜单提供重命名与删除；这些操作也必须支持
键盘访问，不依赖鼠标右键。

新建项目使用轻量对话框输入名称，创建成功后直接进入新项目的导入步骤。删除项目使用
二次确认对话框，明确说明将永久删除项目配置、缓存和生成结果，但不会删除共享素材。
运行任务的项目禁用删除并显示原因。

### 9.3 素材库

素材库使用“视频素材”和“PLY 素材”两个独立页签，每个页签保持自己的导入按钮和列表
状态，不混排两类素材。素材卡片显示原始文件名、大小、首次导入时间和引用项目数量；
展开引用信息可查看项目名称。未引用素材显示删除操作，被引用素材的删除操作禁用并
解释原因。存在活动项目时显示“用于当前项目”。

### 9.4 禁用原生右键菜单

应用入口在 `document` 捕获阶段注册单个 `contextmenu` 监听器并调用
`event.preventDefault()`，覆盖连接页、首页、素材库和工作流。卸载时移除同一个监听器，
避免 React Strict Mode、热重载或测试产生重复注册。本次不实现自定义右键菜单，所有
功能均通过可见按钮和键盘提供。

## 10. 旧项目迁移

当新目录索引不存在但旧 `project_root/project.json` 存在时，启动迁移器执行一次可
重复迁移：

1. 严格读取旧项目并记录迁移版本；
2. 把旧项目引用的视频与 PLY 分别导入共享素材暂存区，完成探测、哈希和去重；
3. 在新的临时项目目录生成使用素材 ID 的新 schema，并迁移所有非输入项目产物；
4. 校验新项目的每个引用和保留产物；
5. 原子激活新项目目录并写入项目目录索引；
6. 目录索引持久化成功后，才删除旧项目中的输入副本和旧目录。

在步骤 5 前中断时，旧项目仍是权威来源；再次启动会复用已提交到素材库的相同哈希
内容并继续迁移。在步骤 5 后但清理前中断时，新目录索引是权威来源，启动恢复只清理
经过身份验证的旧目录。任何失败都不得同时修改旧权威项目和暴露半完成新项目。

## 11. 错误处理与安全边界

- 项目名为空、过长或重名：拒绝并保留对话框输入；
- 项目不存在、损坏或被另一实例锁定：保持当前项目并返回可操作错误；
- 当前任务排队或运行：禁止切换和删除，不自动取消任务；
- 素材导入取消或失败：清理本次暂存，不污染索引；
- 素材重复：返回已有素材，不把它当作错误；
- 素材被引用：拒绝删除并返回引用项目；
- 素材内容缺失或身份不符：拒绝工作流读取并报告素材损坏；
- 项目删除在目录暂存或索引提交前失败：恢复原目录并保持首页项目；索引已提交但物理
  清理失败：项目保持逻辑删除，并通过内部待清理记录重试；
- 目录索引或素材索引损坏：停止相应写操作，避免扫描结果覆盖损坏权威文件；
- 所有删除、迁移、解析和导入路径都先解析为绝对路径，并验证位于精确配置根目录内；
- 不跟随软链接、junction、Windows 重解析点或索引中的越界相对路径；
- API 错误不暴露绝对路径、令牌、worker 命令或配置内容。

## 12. 验证策略

### 12.1 Python 单元测试

- 项目创建、枚举、更新时间、重命名与不区分大小写的重名保护；
- 项目目录索引和素材索引的严格校验、锁定与原子保存；
- 视频/PLY 分类、SHA-256 去重、暂存清理和内容解析；
- 素材引用扫描、引用保护删除和待清理恢复；
- 活动项目两阶段切换、目标失败回滚、会话关闭与项目锁释放；
- 任务运行时切换/删除冲突；
- 旧项目迁移在每个提交边界中断后的可重复恢复；
- 路径越界、软链接、junction、重解析点和文件身份变化拒绝。

### 12.2 API 集成测试

- 项目 CRUD、活动项目切换和无活动项目响应；

## 13. 验收标准

1. 应用启动进入项目首页，可以创建、继续、重命名和删除多个项目。
2. Logo 在首页、素材库和工作流中始终返回项目首页。
3. 项目目录不保存导入视频或 PLY，多个项目可以安全复用共享素材。
4. 视频和 PLY 在素材库中使用独立页签，不混排。
5. 重复导入相同素材不会生成第二份文件。
6. 被项目引用的素材无法删除，并能看到引用项目；删除项目不会删除素材。
7. 有任务运行时无法切换或删除项目，且任务不会被自动取消。
8. 项目切换失败不改变当前活动项目或其工作流状态。
9. 现有单项目及其素材和生成物可以无数据丢失地迁移。
10. 鼠标右键不会显示浏览器原生菜单，所有操作仍可通过按钮和键盘完成。
