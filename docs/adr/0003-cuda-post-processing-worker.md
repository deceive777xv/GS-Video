# 后处理在独立 CUDA worker 中执行

代表帧与全片 `post_process` 使用同一个数学效果引擎，但运行在隔离的 CUDA worker 生命周期中；它沿用现有 GPU 生命周期门禁，而正常开始后处理时分割、ViPE 与 GS 渲染已经结束，不存在同一工作流内的并行争用。后期处理页按需维持预热的最新请求优先预览会话，离开页面、切换项目或启动全片任务时终止会话并释放显存；全片任务使用独立的批处理生命周期。选择 GPU 是为了使全分辨率 Bloom、3D LUT 与锐化具备可接受的处理速度，代价是新增 worker 协议、显存预算和运行环境验证。生产环境不允许静默回退到 CPU：CUDA 不可用或 worker 初始化失败时，阶段必须返回可修复错误，避免代表帧与全片使用不同实现。单帧超出显存预算时必须在原分辨率下使用带足够重叠的分块处理，分块只允许影响速度；最小安全分块仍不可执行时才返回可修复的显存不足错误。
