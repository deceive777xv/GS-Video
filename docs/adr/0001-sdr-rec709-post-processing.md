# 合成后处理统一使用 SDR Rec.709

GS Video 的源素材、合成后处理、代表帧、视频预览和最终导出统一采用 SDR Rec.709 色彩契约，效果引擎接收浮点图像与显式色彩上下文，以避免连续的 8-bit 量化并为未来扩展色彩配置保留稳定接口。前景与 GS 背景必须先转换到 Rec.709 线性光再执行 Alpha 合成，即使这会使半透明边缘不再与旧版的非线性混合逐像素一致。基础合成与处理后帧均以带有明确色彩清单的 16-bit 无损 RGB 缓存持久化，效果链内部使用 `float32`；只有 MP4 编码才转换为带确定性抖动、Rec.709 元数据和 limited range 的 8-bit `yuv420p`，H.264 与 H.265 使用同一像素格式契约。效果链保留超出归一化显示范围的浮点中间值，只在效果自身输入域与最终 SDR 输出转换中执行明确的映射或钳制。首版只允许 SDR Rec.709，不支持 HDR、HLG、PQ 或广色域工作流；明确标记为不受支持色彩的素材必须拒绝，色彩元数据缺失时则要求用户明确确认按 SDR Rec.709 解释，并把该假设纳入项目输入契约与缓存键。系统不得在效果链之前静默执行色调映射。
